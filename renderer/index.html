    Sources

    Libretro: covers, screenshots, title screens. GameTDB: Switch covers, back covers, cartridge labels. No account needed; availability varies by game.

    Settings

    Set a ROM folder for each system. To use several folders (e.g. two SD cards), click “+ Add” or separate paths with |.

    Prompt labels follow your physical controller, regardless of the emulated system. Override the family if your adapter reports a generic name.

    Artwork folders

    For each game PyroCade looks in <Artwork folder>\<system>\, then <ROM folder>\media\, then the ROM folder itself. Either layout works:

    One folder per game                 ES-DE / Skraper style
ps2\Neon Drift (USA)\front.png      ps2\covers\Neon Drift (USA).png
                    \back.png          \backcovers\…
                    \spine.png         \physicalmedia\…   (disc / cart)
                    \disc.png          \manuals\….pdf
                    \manual.pdf        \screenshots\…
                    \screenshot.png    \fanart\…
                    \fanart.jpg        \videos\….mp4
                    \video.mp4
                    \info.json  {"title","year","developer","publisher","genre","players","description"}

    An EmulationStation gamelist.xml in the ROM folder is also read for titles and descriptions. Anything missing gets generated art.
